# Agent 端到端 A/B：用 NOVA 与不用 NOVA（2026-10-19）

[Benchmark 方案](README.md) · 原始数据 [agent-ab-20261019-pi-gpt61sol.jsonl](agent-ab-20261019-pi-gpt61sol.jsonl) · 脚本 [bench/agent_ab/](../../../bench/agent_ab/)

同一 Agent、同一模型、同一问题，比较接入 NOVA（只开放 `search_context`）与不接入时的工具调用、耗时、上下文和正确率。

## 设置

| 项 | 值 |
|---|---|
| Agent | Pi v1.0.2，`pi -p --mode json`，无会话、无项目上下文文件 |
| 模型 | xiugou `gpt-6.1-sol`，thinking=medium |
| NOVA | 本地 bench 服务（commit 177d48f），HTTP MCP，只开放 `search_context`（排除 `ask_project`） |
| NOVA 组提示 | 追加系统提示：先用 search_context 检索，结果里已有的代码直接用于回答，必要时再读文件 |
| 两组共同 | 禁用 edit/write；提问附“给出关键文件路径与行号，300 字以内” |
| 题目 | `bench/agent_ab/questions.jsonl`：5 仓库（muduo / fastapi / pi / cc-switch / gkd）各 4 题，共 20 题 |
| 次数 | 每题每组 2 次，共 80 次；10 路并发，交错顺序 |
| 评审 | gpt-6-astra，`SCENARIO_ASK_PROMPT` 判大意是否答对 |

指标口径：耗时为进程墙钟；工具调用为 `tool_execution_start` 次数；上下文为最后一轮的
input + cacheRead + cacheWrite + output（与 Pi 状态栏一致）；花费按配置单价（input 4 / output 20 / cacheRead 0.4 $/M）估算，
只用于两组相对比较，不是实际账单。

## 结果（40 次 vs 40 次）

| 指标 | 不用 NOVA | 用 NOVA | 变化 | NOVA 更优题数 |
|---|---|---|---|---|
| 正确率 | 35/40 | 36/40 | 持平 | — |
| 工具调用（中位 / 合计） | 6 / 269 | 5 / 201 | 合计 -25% | 18/20 |
| 耗时（中位 / 合计） | 25.5 s / 1068 s | 25.3 s / 1021 s | 合计 -4% | 13/20 |
| 上下文（中位） | 11.0k | 13.2k | +20% | 6/20 |
| 花费（合计，估算） | $3.52 | $3.97 | +13% | 7/20 |

NOVA 组工具分布：search_context 45、read 104、bash 52；不用 NOVA 组：bash 125、read 144。

### 分仓库（中位）

| 仓库 | 耗时 | 工具调用 | 上下文 | 正确 |
|---|---|---|---|---|
| muduo（C++） | 22.3 → 17.4 s | 6 → 3.5 | 8.8k → 11.5k | 8/8 → 8/8 |
| gkd（Kotlin） | 31.4 → 27.3 s | 8.5 → 6 | 15.5k → 12.9k | 5/8 → 7/8 |
| fastapi（Python） | 26.3 → 25.3 s | 6.5 → 5 | 9.4k → 12.6k | 8/8 → 8/8 |
| pi（TypeScript） | 32.1 → 30.2 s | 8 → 7 | 16.8k → 18.2k | 6/8 → 6/8 |
| cc-switch（Rust） | 24.9 → 26.8 s | 6 → 5 | 13.7k → 14.5k | 8/8 → 7/8 |

## 结论

- 稳定收益是工具调用减少（18/20 题更少，合计 -25%），正确率不降。
- 耗时整体持平，只在 muduo、gkd 上明显变快（-22%、-13%）。
- 上下文与花费不占优：search 一次返回数千 token，NOVA 组拿到结果后仍平均读文件 2.6 次。

## 复现

```bash
export EMBED_MODEL=voyage-code-4 NOVA_BENCH_DATA=$HOME/.nova/bench-data-code4 NOVA_BENCH_PORT=8894
bench/stack.sh up                                   # 5 个靶场需已索引（bench/run.py index）
XIUGOU_API_KEY=... python3 bench/agent_ab/setup_agents.py
python3 - <<'EOF' > bench/agent_ab/jobs.txt         # 每题每组 2 次，交错顺序
import json
qs = [json.loads(l) for l in open("bench/agent_ab/questions.jsonl")]
for rep in ("r1", "r2"):
    for q in qs:
        for arm in (("nova", "base") if rep == "r1" else ("base", "nova")):
            print(f"{arm}\t{q['id']}.{rep}\t{q['repo']}\t{q['query']}")
EOF
bench/agent_ab/run_all.sh > bench/agent_ab/run_all.log
uv run python bench/agent_ab/judge_pi.py            # 写 bench/agent_ab/judged.jsonl
rm -rf bench/agent_ab/agent-*                       # 删除含 key 的配置
```
